# 0049. 普通用户公开公司资料接口

- 日期：2026-11-21
- 状态：已实施

## 背景

用户确认公司全称、公司简介和公司营业执照向普通用户公开。现有资料只能由管理后台维护，App 没有查询入口。

## 决定

- `[PRD]` 新增 `GET /api/v1/company-profile/`，无需登录即可查询公司全称、公司简介和营业执照。
- `[DESIGN]` 营业执照只返回短期签名 `display_url` 及过期时间，不返回认证内容地址、存储路径、管理员或版本信息。
- `[DESIGN]` 公司资料不存在时返回空资料，不制造不存在错误，方便 App 首次启动展示。
- `[DESIGN]` 公开接口只读；公司资料和营业执照仍由 `/admin/v1/settings/company-profile/` 管理。
- `[CONFIRM]` OCR、人工核验、营业期限提醒和多公司主体仍不在本期范围内。

## 影响

- App 可在无需登录的公司介绍或关于页面展示公开公司资料。
- 不改变管理后台维护、媒体存储、支付、认证或生产配置。
