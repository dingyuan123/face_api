# 0053. 管理员强制注销和余额清空

- 日期：2026-11-23
- 状态：已实施

## 背景

用户可能保有低于最低提现门槛的推广奖励或其他余额，无法通过普通提现完成资金清零，因此普通注销条件长期无法满足。

## 决定

- `[PRD]` 普通提现继续保持最低提现门槛；管理员可清空无法提现余额并执行强制注销。
- `[DESIGN]` 余额清空写入钱包和收益 `ADJUSTMENT` 不可变流水，取消待结算收益、推广奖励和处理中提现，不直接无痕修改余额。
- `[DESIGN]` 强制注销使用独立 RBAC 权限，必须填写原因并保存执行前条件快照、清空金额、清理数量和管理员标识。
- `[DESIGN]` 强制注销跳过资金门槛，但保留订单、支付、退款、提现、聊天、客服、评价和安全审计事实。
- `[CONFIRM]` 生产环境是否由客服直接执行，还是需要财务复核、二次审批和实际打款凭证。

## 影响

- 新增强制注销和余额清空管理接口、权限点、审计字段和迁移。
- 不降低普通用户正常注销的资金保护条件。
