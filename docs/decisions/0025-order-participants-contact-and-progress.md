# ADR 0025: 订单双方信息、电话联系和进度时间线

- 状态：Accepted
- 日期：2026-11-03
- 范围：订单详情参与方资料、服务者统计、电话联系和状态时间线

## 背景

订单详情需要展示见面双方昵称、头像和服务者履约信息，并允许双方通过电话联系。当前账号只保存手机号哈希和脱敏手机号，无法恢复可拨号号码。

## 决策

- `[DESIGN]` 订单详情返回普通用户昵称、头像、脱敏手机号，以及服务者昵称、头像、评分、评价数、完成单数和认证状态。
- `[DESIGN]` 新增 `User.phone_encrypted`，使用服务端身份加密密钥保存完整手机号；登录时补充，已有用户下次登录后恢复可拨号能力。
- `[DESIGN]` `contact` 只返回当前登录者需要联系的对方手机号、`tel_uri`、可拨号状态和按钮文案，不同时暴露双方完整号码。
- `[DESIGN]` 订单进行中允许拨号；订单完成后仅评价窗口内允许拨号；取消、退款或超出窗口后关闭拨号。
- `[DESIGN]` 时间线来自 `order_status_logs`，返回事件、状态、状态文案、角色、时间和原因。
- `[DESIGN]` `next_action` 返回角色、动作代码和前端按钮文案，客户端不得据此修改服务端状态。
- `[DESIGN]` 完整手机号不写日志、trace、缓存或订单列表；虚拟号码和隐私中转后续独立评估。

## 影响

- 新增手机号密文字段和迁移，不改变手机号登录哈希模型。
- 订单详情接口同时支持普通用户和服务者读取，并按访问者返回不同的联系对象。
- 前端可以直接使用 `tel_uri` 发起拨号，但旧用户需重新登录后才能启用。
