# ADR 0010: 服务者入驻申请与开发期身份 Mock

- 状态：Accepted
- 日期：2026-10-28
- 范围：账号首次身份选择、服务者入驻申请、最小管理员审核

## 背景

产品已确认首次登录后选择普通用户或服务陪伴者；服务者当前申请头像、至少三张生活照、个人简介、真实姓名和身份证信息。实名和人脸在真实服务商接入前使用 Mock，同一个用户只允许一个进行中的申请。该范围不是最终服务者资料模型。

## 决策

- `[PRD]` 首次身份选择只决定默认工作区，不直接授予服务者权限；同值重复幂等，异值冲突。
- `[PRD]` 申请生活照默认最少 3 张，最小/最大数量由 `PROVIDER_APPLICATION_MIN_LIFE_PHOTOS/MAX_LIFE_PHOTOS` 配置。
- `[PRD]` 数据库部分唯一约束限制一个用户只能有一个 `PENDING/APPROVED` 申请；拒绝/取消后可携带版本重提。
- `[PRD]` 实名和人脸开发 Mock 返回 `MOCK_PASSED`；生产配置禁止 Mock，并预留真实适配器替换点。
- `[DESIGN]` `real_name/id_card_number` 为写入专用字段，使用可轮换密钥加密；身份证只另存带密钥 HMAC。响应、日志、事件和管理员列表均不返回明文。
- `[DESIGN]` 创建申请按用户和 `Idempotency-Key` 去重；重提和审核使用 `expected_version` 防止并发覆盖。
- `[DESIGN]` 申请状态事件追加保存提交、重提、通过、拒绝、操作者、原因和 trace_id。
- `[DESIGN]` 当前媒体字段是不透明资源 ID；媒体上传、存在性、所有权和内容审核由后续媒体/存储模块负责。
- `[DESIGN]` 当前最小审核接口使用 `is_staff` Bearer 认证，不代表最终后台 RBAC 和安全等级。

## 后果

- 可以完成首次身份选择到服务者申请、审核、拒绝重提的最小闭环。
- 真实认证接入时只替换认证适配器和状态映射，不应把服务商 SDK 扩散到申请模块。
- 申请最终字段、媒体规则、审核 SLA 和正式管理员安全方案仍需确认；确认后通过迁移、配置版本和 ADR 增量演进。
