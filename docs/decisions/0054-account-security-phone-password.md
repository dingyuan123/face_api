# 0054. 账号密码、找回密码和手机号更换

- 日期：2026-11-24
- 状态：已实施

## 背景

客户端需要支持普通用户设置/修改登录密码、忘记密码找回和更换绑定手机号。现有验证码基础设施可复用，但此前没有普通用户密码找回和安全换绑流程。

## 决定

- `[PRD]` 新增账号安全查询、密码设置/修改、忘记密码、手机号更换申请和确认接口。
- `[DESIGN]` 密码为 8 到 64 位且同时包含字母和数字；首次设置使用短信验证码，修改已有密码还需当前密码。
- `[DESIGN]` 忘记密码使用绑定手机号验证码，成功后撤销全部设备令牌；密码修改保留当前设备并撤销其他设备令牌。
- `[DESIGN]` 已绑定手机号的换绑使用新旧手机号双验证码；无手机号账号使用当前密码和新手机号验证码。
- `[DESIGN]` 新手机号已被其他账号绑定时拒绝换绑，不在本流程内自动合并账号。
- `[DESIGN]` 新增账号安全审计和换绑请求表，不保存明文密码、手机号、验证码或令牌。
- `[CONFIRM]` 阿里云短信正式签名/模板、换绑后的登录设备策略和客服人工协助边界。

## 影响

- 新增账号安全 API、验证码用途、审计/换绑请求模型和迁移。
- 不改变已有手机号绑定、第三方登录和账号注销接口的兼容字段。
