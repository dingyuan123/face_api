# ADR 0011: 开发期本地媒体存储与云存储适配边界

- 状态：Accepted
- 日期：2026-10-29
- 范围：服务者申请头像、生活照上传和私有读取

## 背景

服务者申请需要上传头像和生活照，但当前尚未选择阿里云 OSS、腾讯云 COS 或其他存储厂商。业务接口需要先具备可测试、可安全处理的媒体能力，后续再替换为云存储和 CDN。

## 决策

- `[PRD]` 当前申请需要头像和生活照；生活照数量规则沿用已确认的配置化范围。
- `[DESIGN]` 当前文件保存到 Django `MEDIA_ROOT` 对应的服务端目录，数据库保存 `media_assets` 元数据，不把原文件写入数据库。
- `[DESIGN]` 只接受单帧 JPEG、PNG、WebP；服务端使用 Pillow 解码、校验尺寸/像素/大小、应用方向并重新编码，移除 EXIF/GPS 等元数据。
- `[DESIGN]` 媒体读取要求 Bearer 认证并校验上传者或 `is_staff`，返回私有、禁止公共缓存的内容。
- `[DESIGN]` 上传按 `Idempotency-Key`、用户、用途和内容哈希去重；服务者申请通过 `media.services` 校验媒体所有权、用途和状态。
- `[DESIGN]` `media.storage` 是存储边界。后续接入 OSS/COS 时只替换保存、读取和签名 URL 实现，不把云厂商 SDK 引入 providers。
- `[CONFIRM]` 云存储厂商、私有桶/CDN、短期签名 URL、图片/视频审核、病毒扫描、保留删除和水印规则。

## 影响

- 可以在没有云存储账号的情况下完成申请图片上传、审核查看和自动化测试。
- 本地文件目录需要持久化和备份；多实例部署前不能继续依赖本地磁盘。
- 上传接口当前为服务端直传，后续如改为客户端直传，需要新增受控上传凭证和回调校验流程。

## 风险与缓解

- 风险：本地磁盘损坏或实例切换导致文件不可用；开发阶段纳入备份，生产前切换对象存储。
- 风险：图片解析器漏洞或超大图片消耗资源；限制格式、大小、尺寸、像素量并重新编码。
- 风险：媒体被越权读取；接口只按所有者/管理员授权并返回 `private, no-store`。

## 验证

- `tests/test_media_upload.py` 覆盖格式、EXIF 清除、幂等、去重和访问控制。
- `tests/test_provider_onboarding.py` 覆盖申请引用本人媒体和拒绝他人媒体。
- 迁移、OpenAPI、Ruff、Django check 和完整 pytest 作为提交门槛。
