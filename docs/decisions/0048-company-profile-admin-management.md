# 0048. 管理后台公司资料和营业执照

- 日期：2026-11-18
- 状态：已实施

## 背景

管理平台需要维护公司全称、公司简介和公司营业执照。当前没有公开公司资料接口，也没有 OCR、证照核验或营业期限管理需求。

## 决定

- `[DESIGN]` 使用 `admin_company_profiles` 单例表保存公司资料，避免通用系统配置承载结构化业务数据。
- `[DESIGN]` 公司资料管理复用 `admin.settings.read/write` 权限，不新增重复权限点。
- `[DESIGN]` 营业执照新增 `COMPANY_BUSINESS_LICENSE` 媒体用途，通过管理端专用上传接口生成媒体引用。
- `[DESIGN]` 公司资料首次创建使用 `expected_version=0`，后续更新使用乐观锁；可选 `Idempotency-Key` 重放同一写请求，同键不同请求返回 409。
- `[DESIGN]` 管理接口返回短期签名 `display_url`，审计只记录媒体 UUID，不记录签名地址或存储路径。
- `[CONFIRM]` 本期不决定公开范围、证照 OCR、人工核验、营业期限提醒或多公司主体；需求确认后另行扩展。

## 影响

- 增加公司资料数据表和媒体用途迁移。
- 增加管理端查询、维护和营业执照上传接口。
- 不修改用户协议、隐私政策、生产配置或现有支付/认证数据。
