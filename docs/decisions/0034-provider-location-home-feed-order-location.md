# ADR 0034：服务者位置、首页距离和订单见面地点

- 状态：已确认
- 日期：2026-11-07
- 决策人：产品、前端和后端共同确认

## 背景

首页需要显示用户与服务者的大致距离，服务者登录后需要更新位置；同时订单必须保存用户选择的完整见面地址。普通用户当前位置只用于浏览服务者，不能形成长期轨迹。

## 决策

- `[PRD]` 只保存服务者当前位置；普通用户当前位置不落库，只在一次首页请求中使用。
- `[DESIGN]` 服务者登录后通过位置接口更新坐标，坐标模糊到约 100 米并使用独立位置密钥加密。
- `[DESIGN]` 服务者位置默认 24 小时有效，可撤销；过期后不参与首页距离。
- `[DESIGN]` `GET /home/feed/` 保持城市浏览，`POST /home/feed/` 用请求体接收临时浏览者坐标并返回一位小数距离。
- `[DESIGN]` 地点搜索签发短期 HMAC `selection_token`；订单使用该凭证保存完整 POI 地址、经纬度和规则版本。
- `[DESIGN]` 订单见面地点只对订单参与人开放，和任何用户实时位置分离。
- `[DESIGN]` 手动地址后续开放，当前订单不接受未经搜索过滤的自定义地点。

## 影响

- 首页可显示模糊距离，同时普通用户位置不形成长期记录。
- 服务者可以控制位置共享并撤销，但要进入附近推荐需要保持有效位置。
- 订单地址具备可追溯快照，前端不能伪造酒店或私人地址。

## 验证

- 自动化测试覆盖位置加密、权限、临时位置不落库、距离精度、凭证校验和订单地点快照。
- 生产还需要验证腾讯位置数据条款、密钥轮换、授权文案、保留期限和数据主体权利流程。
