# ADR 0012: 当前设备会话退出与令牌撤销

- 状态：Accepted
- 日期：2026-10-29
- 范围：手机号登录后的退出登录

## 背景

登录接口已经签发不透明访问/刷新令牌并按 `session_id` 保存设备会话。用户需要退出登录，且退出后当前设备的访问令牌和刷新令牌都必须失效，同时不能误伤其他设备。

## 决策

- `[PRD]` 登录用户可以退出当前登录会话。
- `[DESIGN]` `POST /api/v1/auth/logout/` 使用当前 Bearer 访问令牌，撤销同一 `session_id` 下所有未撤销令牌。
- `[DESIGN]` 退出只影响当前设备会话；其他设备的访问/刷新令牌继续有效。
- `[DESIGN]` 退出为状态幂等操作。首次请求成功后凭证被撤销，网络重试返回 401，但不会产生额外副作用。
- `[DESIGN]` 退出与刷新通过用户行锁串行，避免并发刷新在退出提交后补发新令牌。
- `[DESIGN]` 响应只返回 `logged_out`，不返回 session_id、令牌或设备敏感信息。
- `[CONFIRM]` 后续是否增加退出全部设备、设备列表、异常远端撤销和强制下线审计。

## 影响

- 客户端退出后必须清理本地令牌，并以 401 作为安全重试后的正常结果。
- 账号注销、封禁和安全事件处置仍需要单独的全会话撤销能力，不在本次范围内。

## 验证

- `tests/test_auth.py` 覆盖当前会话访问/刷新令牌失效、其他会话保留和无认证拒绝。
- 完整 pytest、Ruff、Django check、迁移检查和 OpenAPI 校验作为提交门槛。
