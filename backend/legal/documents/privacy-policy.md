我们不会在未获得相应授权或缺乏合法处理依据的情况下，持续获取您的精确位置。

您主动发送给其他用户的位置，将按照您发送时选择的对象和业务场景进行展示。

### 2.4 实名认证及人脸认证

为保障平台交易安全、服务者身份真实性以及相关法律法规要求，我们可能向符合条件的用户提供实名认证和人脸核验功能。

1. 核验用户身份；
2. 验证服务者身份真实性；
3. 防止冒用身份；
4. 保障平台交易安全；
5. 满足适用法律法规的要求。

上述信息中的身份证件信息及生物识别信息属于敏感个人信息。

我们仅在具有特定目的、充分必要性并采取严格保护措施的情况下处理相关信息。

在开展实名认证或人脸认证前，我们将通过单独的授权页面向您说明：

- 具体收集的信息；
- 处理目的；
- 处理方式；
- 必要性；
- 保存期限或确定方式；
- 对个人权益可能产生的影响；

如果您拒绝提供相关认证信息，可能无法使用必须通过相应认证才能开通的服务者功能，但不应因此被不合理地限制使用与认证无关的其他基本功能。

我们不会在未经合法授权的情况下将您的身份证件信息或人脸信息公开展示给其他普通用户。

## 第五章 个人信息存储及保护

### 5.1 存储地点

原则上，我们在中华人民共和国境内收集和产生的个人信息将在中国大陆境内存储。

如果未来因业务需要向境外提供个人信息，我们将按照适用法律法规履行相应的告知、单独同意及其他合规程序。

### 5.2 保存期限

我们仅在实现处理目的所必要的最短期限内保存个人信息。

不同类型信息的保存期限如下：

| 信息类型       | 保存期限原则                         |
| -------------- | ------------------------------------ |
| 账号及基础资料 | 账号存续期间；注销后依法处理         |
| 登录及安全日志 | 按法律法规及安全管理要求保存         |
| 实名认证信息   | 按认证目的、法定要求及必要期限保存   |
| 人脸识别信息   | 按认证服务实际方案和合法保存期限处理 |
| 用户动态及评论 | 用户删除或注销前；依法需要留存的除外 |
| 聊天信息       | 按聊天服务必要期限及争议处理需要保存 |
| 订单及支付记录 | 按财务、税务及交易相关法律要求保存   |
| 投诉举报信息   | 按调查处理及法定留存期限保存         |
| 设备运行日志   | 按安全和故障排查所需期限保存         |

保存期限届满后，我们将删除相关个人信息或进行匿名化处理；法律法规另有规定的，从其规定。

### 5.3 安全保护措施

我们采取合理且必要的安全技术和管理措施，包括：

1. 数据访问权限控制；
2. 身份认证及权限管理；
3. 数据传输加密；
4. 重要信息加密存储或脱敏处理；
5. 安全日志记录；
6. 数据备份及恢复机制；
7. 员工保密及安全管理制度；
8. 安全风险监测及应急响应。

我们会持续改进个人信息保护措施。

如发生或可能发生个人信息泄露、篡改、丢失等安全事件，我们将依法采取补救措施，并根据法律规定向有关主管部门和个人履行通知义务。

在符合法律规定的情况下，您可以申请删除个人信息。
